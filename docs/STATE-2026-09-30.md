## In build 5

**Security**
- **Both databases on the phone are encrypted** — SQLite3MultipleCiphers,
  one key per phone in the Android Keystore. An updating phone encrypts its
  outbox in place (unsent work kept) and downloads the synced copy again once.
  Android backup is off. Design in CLAUDE.md, "Encryption at rest".
- **One technician per phone.** The first to sign in registers it; anyone
  else is refused after the server accepts their password. Reinstalling the
  app releases it.

**Login fixes (both bugs are in builds 3 and 4)**
- Log out now returns to the login screen. Signing in pushed the dashboard
  over the auth gate, so logout left a dashboard with nobody signed in.
- The company is kept on log out — asked only on a phone's first sign-in.

**Certificates**
- Pass / Fail / N/A are radio buttons, in Create Certificate and read-only in
  the certificate view.
- Test Description / Test Value / Actual headings on every line, both
  screens; "-" where a line has nothing.
- Actual box: tinted, 100 dp, normal keyboard (a reading can be a word).
- Facility Contact name only when the template asks for a facility signature.
- "Certificate created" after issuing.
- TECH SIGNED and CLIENT SIGNED chips on the list and the view.

**Artwork** — gear icon, no tick/badge icons, v2 store graphics.
